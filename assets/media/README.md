# Curated Media

This folder is reserved for selected screenshots, project images, and other visual media shown on `media.html`.

Suggested naming:

- `battlezone-<subject>.jpg`
- `project-<name>-<subject>.png`
- `showcase-<subject>.webp`

Prefer web-friendly JPG/WebP for large screenshots and PNG when transparency or lossless UI detail matters. Keep only deliberately curated media here; the full archives remain on Steam and YouTube.
